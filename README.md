Ein kleines Projekt, um eine Soullink-Challenge zu vereinfachen. Das Projekt basiert auf HTML, CSS und JavaScript.

Diese Seite basiert auf eine Datenmenge von einem Google-Sheet Dokument. Da das Google-Sheet Dokument komisch gecached wurde, wird das Dokument als JSON behandelt.

Der Code für das Apps Script ist ebenfalls im Repos vorhanden (für den Statistiken-Counter).

1. Die normale Tabelle (Paare)
2. Wipeout Daten (H3:I5)
3. Death Counter (H14:I16)

Solange die pokemon.json aktuell ist, können immer genaue Daten (Name, Typen und den Pokewiki-Link) abgerufen werden.
Die Spielernamen sind variabel, sowie die Spieleranzahl (Spaltensortierung: Ort, Spielernamen, Gültigkeit TRUE/FALSE).

Damit die HTML-Seite auch funktioniert, muss das GoogleSheet-Dokument von den Spaltenbezeichnungen genau gleich aufgebaut werden.
